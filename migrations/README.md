# Database Migrations

This directory contains Alembic database migrations for Tele-Sum.

## Usage

### Create a new migration
```bash
alembic revision --autogenerate -m "Description of changes"
```

### Apply migrations
```bash
alembic upgrade head
```

### Rollback one migration
```bash
alembic downgrade -1
```

### View migration history
```bash
alembic history
```

## Railway Deployment

Migrations are automatically applied on deployment via the startup script.
You can also manually run migrations:

```bash
railway run alembic upgrade head
```

## Important Notes

- Always review autogenerated migrations before applying
- Test migrations locally before deploying to production
- The initial migration (001_initial_schema) creates all base tables with indexes
